# FPパス（仮称） — FP3級 学科対策アプリ 商用版

FP技能検定3級 学科試験対策の学習アプリ(PWA)。商用展開を前提としたプロダクトで、個人用アプリ(`fp3/`)とはブランド・コード・保存データ(`fpp_*`)を完全に分離しています。

**2025年度試験対応(法令基準日: 2025年4月1日)**

## 機能(Phase 1 実装済み)

- **合格予測** — 分野別累計正答率から本試験の期待得点(/60点)を推定し、合格圏/ボーダー/要強化をホームと成績画面に表示。弱点分野も提示
- **連続学習日数(ストリーク)** — 毎日の学習を🔥で可視化し、継続を動機付け
- **学習リマインダー** — 通知許可+Periodic Background Sync(対応端末のみ)による毎日の学習通知
- **アクセス解析フック** — `index.html` 冒頭の `GA_ID` にGA4計測IDを設定すると計測が有効化
- **問題データ機械検証** — `node validate.js [期待問題数]` でID連番・正解キー・解説文字数・wrong_reasons網羅を検証(CI組み込み用)

## 機能(Phase 0: 商用ベース版)

- **ホーム画面** — 学習/模試/成績の3モード選択と進捗サマリー
- **学習モード** — 20問セッション・間隔復習(間違いは30問後に再出題)・分野別ドリル
- **模試モード(本試験形式)** — ○×30問+三答択一30問・90分タイマー・問題ジャンプナビ・合格判定(36/60点)・分野別分析・誤答レビュー。模試で間違えた問題は学習モードの復習キューに自動登録
- **成績・履歴** — 分野別累計正答率と模試の受験履歴(直近50回)
- **コンプライアンス表示** — 試験実施団体との無関係の明示・合格非保証の免責

## 事業計画との対応

事業計画書のロードマップにおける **Phase 1** まで実装済み(問題300問・合格予測・リマインダー・解析フック)。以降の実装予定:

- Phase 1 残り: Google Play(TWA)掲載・SEO記事(いずれも独自ドメイン公開後の作業)
- Phase 2: アカウント/クラウド同期・Stripe決済・AI解説チャット・実技対策
- Phase 3: FP2級版(収益の本命)

## Google Play 掲載手順(TWA)

独自ドメインでHTTPS公開した後に実施:

1. `npx @bubblewrap/cli init --manifest https://<ドメイン>/manifest.json` でAndroidプロジェクト生成
2. `npx @bubblewrap/cli build` でAAB(署名キー生成含む)をビルド
3. 署名キーのSHA-256フィンガープリントを `https://<ドメイン>/.well-known/assetlinks.json` に配置(bubblewrapが雛形を出力)
4. Google Play Console(登録料$25)にAABをアップロード

## アクセス解析(GA4)

`index.html` 冒頭の `const GA_ID=''` にGA4の計測ID(`G-XXXXXXXXXX`)を設定すると有効化されます。未設定時は外部通信を行いません。

## ファイル構成

```
index.html    アプリ本体(ホーム/学習/模試/成績の全ビュー)
questions.js  問題データ(fp3と同一の120問から開始。Phase 1で拡充)
sw.js         Service Worker(index.html / questions.js はネットワーク優先)
manifest.json PWA マニフェスト
icons/        アプリアイコン(インディゴ)
```
