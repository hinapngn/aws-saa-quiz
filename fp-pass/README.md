# FPパス（仮称） — FP3級 学科対策アプリ 商用版

FP技能検定3級 学科試験対策の学習アプリ(PWA)。商用展開を前提としたプロダクトで、個人用アプリ(`fp3/`)とはブランド・コード・保存データ(`fpp_*`)を完全に分離しています。

**2025年度試験対応(法令基準日: 2025年4月1日)**

## 機能(Phase 0: 商用ベース版)

- **ホーム画面** — 学習/模試/成績の3モード選択と進捗サマリー
- **学習モード** — 20問セッション・間隔復習(間違いは30問後に再出題)・分野別ドリル
- **模試モード(本試験形式)** — ○×30問+三答択一30問・90分タイマー・問題ジャンプナビ・合格判定(36/60点)・分野別分析・誤答レビュー。模試で間違えた問題は学習モードの復習キューに自動登録
- **成績・履歴** — 分野別累計正答率と模試の受験履歴(直近50回)
- **コンプライアンス表示** — 試験実施団体との無関係の明示・合格非保証の免責

## ファイル構成

```
index.html    アプリ本体(ホーム/学習/模試/成績の全ビュー)
questions.js  問題データ(fp3と同一の120問から開始。Phase 1で拡充)
sw.js         Service Worker(index.html / questions.js はネットワーク優先)
manifest.json PWA マニフェスト
icons/        アプリアイコン(インディゴ)
```
